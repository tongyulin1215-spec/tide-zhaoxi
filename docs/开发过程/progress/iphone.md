### 功能自查（对照方案第二至四节）
- 已做：底部图标栏与设置齿轮；三处底部输入条；点圈打勾、点行编辑、左滑删除、长按菜单（移到 / 写感想 / 删除）、摇一摇撤销；首页、规划、日程（竖屏单天 + 横屏一周、待办卡片拖入或点选）、记账（四种截图入口 + 分享）、总结（两层）；设置（新的一天、同步、每晚提醒）；同步（配对、逐条合并、首次备份、30 秒 / 改动后 / 回到前台触发）；小组件（小 / 中 / 大 + 锁屏）；快速记一条（快捷指令 / 操作按钮 / 控制中心）。
- 与方案不同：
  - 日程不能在手机上拖出一段新时间（竖向拖动要留给滚动），点空白新建 1 小时再改。
  - 「分享 → 朝夕」在分享面板里直接弹一个精简的确认表单（扩展打不开主 App）。
  - 控制中心按钮会打开 App 的「记一条」；快捷指令 / 操作按钮不打开 App，直接问「记什么？」。
- 建议改进（未做）：
  1. 同步状态在首页无提示，连不上时只在设置里看得到。
  2. 小组件点按只打开首页，可改为直接到那一天或那一条。
  3. 记账统计可加「按天」柱状图，方便看一个月里哪几天花得多。
  4. 免费签名 7 天到期前没有提醒，可在到期前一天让 App 提示重装。

### 留给后续的问题（审查 Minor）
- 某台设备超过 30 天没同步，期间别处删掉的记录可能回来。
- 正在同步时的改动，最多要等 30 秒才同步。
- App 进后台时未取消进行中的同步，极少数时机下可能覆盖分享扩展刚记的一笔。
- day-start.json 换了格式，旧版 Mac 朝夕读出来会是 0 点。
- Mac 同步口对单条消息大小限制偏宽（200 MB）。
- 两台设备时钟不准时，「以后改的为准」会偏向时钟快的一方。
- 同步内容在局域网内不加密（家用 Wi-Fi 下可接受）。
- 深色模式未在模拟器上核对，需真机看。
