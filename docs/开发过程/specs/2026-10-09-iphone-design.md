# 朝夕 iPhone 版 — 方案

日期：2026-10-09　状态：已逐段确认，待用户审阅本文档

## 目标
把 Mac 版朝夕的全部功能搬到 iPhone，界面按手机习惯重做；两边数据在同一 Wi-Fi 下互通。用户平时直接打开 App 使用，小组件、快速记等入口做成可选、默认不打扰。

## 既定前提（沿用 10-03 方案，10-09 确认）
- 一次做完整 App（不再分「先随手记」两步）。
- iOS 免费签名，7 天重装一次（提供一键重装脚本）。
- 同步：同一 Wi-Fi 下以 Mac 为中转，本地同步；不走 iCloud。
- 系统要求：iOS 17 及以上。

## 一、整体结构
- 同一项目里两个 App，共用底层逻辑（识别规则、首页计算与 DDL 折叠、重复/阶段、记账统计与余额、总结与感想、日程规则）；现有测试继续覆盖。
- 界面各自实现：手机版全新写，Mac 版界面不受影响。
- 手机本地数据格式与 Mac 完全相同（待办 / 记账 / 日程三个文件）。

## 二、手机界面
- 底部图标栏：首页、规划、日程、记账、总结；设置在首页右上角齿轮。
- 输入条在底部（首页、规划、记账），随键盘上移。
- 手势：点圆圈打勾；点一行弹出底部编辑卡片（含改名）；左滑删除；长按出菜单（移到、写感想等）；摇一摇撤销。
- 首页：日期 + ‹ › + 日历；筛选 / 拉入标签 / 排序收进「…」；「总结一下今天」「整理拖延」；未完成、DDL 折叠、已完成。
- 规划：模块组卡片单列；卡片头可收起；末尾「＋ 加一项」。
- 日程：竖屏单天（顶部周日期条，左右滑换天），右下「待办」按钮拉出底部待办卡片，拖入或点选后点时段；长按日程块拖动、拖下边缘改时长；横屏为七天周视图。
- 记账：顶部收入 / 支出 / 净收入 / 余额；流水 / 统计；输入条旁相机按钮（拍照、相册多选、粘贴）；刚截过付款图时顶部提示「记录这张？」（需相册权限）；分享菜单「分享 → 朝夕」直接弹确认表单。
- 总结：两层——列表（每日总结、模板、感想、报告）→ 详情；「新建」在右上角。
- 设置：新的一天开始时间、每晚提醒（默认关）、与 Mac 的同步状态（上次同步、是否连上）、连接 Mac。

## 三、同步
- Mac 上的朝夕（常驻菜单栏）在局域网开同步口；手机在同一 Wi-Fi 下自动发现。
- 首次配对：手机点「连接 Mac」，Mac 显示 4 位数字，手机输入；之后自动连接。
- 触发：手机打开 App、手机改动后几秒、App 开着时每 30 秒。离开 Wi-Fi 照常使用，下次连上补同步。
- 合并：每条记录（待办、模块组、账目、日程、感想、随笔、总结等）记最后修改时间，删除留记号；逐条比较、新者胜；同一条两边都改时以后改的为准。
- 同步内容：全部规划数据、记账、日程、感想、总结、「新的一天开始时间」。不同步：每晚提醒开关与时间、小组件筛选、窗口 / 界面偏好。
- 安全：首次与手机同步前，Mac 先把全部数据备份到「文稿/朝夕备份」。
- 数据改造：每条记录新增「最后修改时间」与删除记号；旧数据视为很早修改；Mac 版照常读写，现有数据不丢。

## 四、可选入口（默认不打扰）
- 主屏幕小组件（小 / 中 / 大）：看今天、打勾、按标签筛选，同 Mac 桌面小组件。
- 锁屏小组件：今天完成数与下一条待办，点按打开 App。
- 快速记一条：控制中心按钮 / 侧边操作按钮 / 快捷指令，弹出一行输入，识别规则同首页。
- 每晚总结提醒：设置里开启，默认关闭；Mac 提醒不变。

## 五、开发顺序（每步可装到手机试用）
1. 数据改造（修改时间、删除记号），Mac 版先更新。
2. 手机 App 骨架 + 首页 + 一键重装脚本（先用手机本地数据）。
3. 规划、日程（竖 / 横）、记账（四种截图入口）、总结、设置。
4. 同步（Mac 同步口、配对、逐条合并）。
5. 小组件（主屏幕、锁屏）、快速记一条、提醒。
6. 功能与视觉整体自查，出改进清单。

## 测试
- 底层逻辑与同步合并写自动测试，重点覆盖两边同时改、删除后再改、离线后补同步。
- 界面用 iPhone 模拟器截图检查，只在用户不用电脑时运行。
- 真机手感由用户试用反馈。

## 不做
iCloud / 付费账号相关能力、iPad 专门布局、Apple Watch、多人共享。
